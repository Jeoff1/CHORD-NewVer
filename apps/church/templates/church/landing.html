How it works

Four steps from a theme to a confirmed {{ labels.lineup|lower }}.

The {{ labels.worship_service|lower }} page walks the people who plan through each step, and tells them what to do next.

{% comment %}The Phase 9C steps (decision 0015): Theme, Praise Team, Song Lineup, Confirm.{% endcomment %}
  1. 1

    {% include "includes/icons/document.html" %}Theme

    The {{ labels.pastor|lower }} posts the theme and the main scripture. Passages are suggested from a stored Bible as you type, and the {{ labels.sermon|lower }} can be attached as a PDF.

  2. 2

    {% include "includes/icons/people.html" %}{{ labels.team }}

    Optional

    Assign who serves that day. Skip it and go straight to the songs.

  3. 3

    {% include "includes/icons/music-note.html" %}Song {{ labels.lineup }}

    Add the songs you have in mind, slot by slot, with songs that fit the theme suggested beside them. Swap, lock, reorder and set keys on the same page.

  4. 4

    {% include "includes/icons/check-circle.html" %}Confirm

    Check the rundown of theme, team and songs, then confirm. The {{ labels.pastor|lower }} has the final say, and the team sees the {{ labels.lineup|lower }} once it's confirmed.

Then the team rehearses {% include "includes/icons/chevron-down.html" %}

Features

Everything the worship team needs, nothing it doesn't.

{% comment %}Only switched-on Modules are offered (AGENTS.md: a switched-off Module is hidden).{% endcomment %}
  • {% include "includes/icons/document.html" %}

    Chord sheets in any key

    Paste a sheet once; CHORD stores it as ChordPro. Each person chooses their own key or a capo.

  • {% include "includes/icons/play.html" %}

    Spotify playback

    Listen to each song right beside its chord sheet, and get the {{ labels.lineup|lower }} saved as a playlist once it's confirmed.

    • {% if "teams" in enabled_modules %}
  • {% include "includes/icons/people.html" %}

    Team roster

    Assign each part for a {{ labels.worship_service|lower }}. People accept, mark when they're away, and ask for a swap.

    • {% endif %} {% if "occasions" in enabled_modules %}
  • {% include "includes/icons/calendar.html" %}

    Calendar and occasions

    Weddings, baptisms and funerals go on the same calendar as each {{ labels.worship_service|lower }}, so nothing gets double-booked.

    • {% endif %} {% if "announcements" in enabled_modules %}
  • {% include "includes/icons/megaphone.html" %}

    Announcements

    Send a note to everyone, or only to the team serving at one {{ labels.worship_service|lower }}.

    • {% endif %}
  • {% include "includes/icons/gear.html" %}

    Fits how your church works

    Your kinds of {{ labels.worship_service|lower }}, song slots, theme tags, seasons and wording are settings your church sets, not built in.

Rehearsal

The sheet, the key and the song, on one page.

Each song in a confirmed {{ labels.lineup|lower }} has its own page. Everyone reads the same chord sheet, plays in the key that suits them, and listens to the track right beside it.

  • {% include "includes/icons/check-circle.html" %}Your own key and capoChange yours without changing anyone else's.
  • {% include "includes/icons/check-circle.html" %}Play along with the trackPractise in the recording's key, with Spotify beside the sheet.
  • {% include "includes/icons/check-circle.html" %}Run through the whole setPrevious and next song, in the {{ labels.lineup|lower }}'s order.
